# Fixtures

This directory holds reusable machine-checkable input data for tests,
validators, profile resolvers, projectors, and execution tools.

Fixtures are not tutorials. They should be stable, minimal, and named by the
behavior or contract they verify.

Planned first areas:

- `logicir/`: core LogicIR documents.
- `profiles/`: architecture profile and stack definitions.
- `features/`: feature payload and extension-record fixtures.
