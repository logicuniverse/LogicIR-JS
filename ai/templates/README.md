# AI Templates

This directory contains reusable templates for AI-assisted work.

Templates are not task output and are not accepted project source. They define
the expected shape of sandbox work so humans can review and promote useful
pieces with less reconstruction. Copy the task template into a new task
directory; do not make a running task write back into the template.

Available templates:

- [`task/`](task/): standard layout for one autonomous AI task under
  `ai/tasks/YYYY-MM-DD-<task>/`.
