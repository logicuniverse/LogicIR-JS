# basic-software-interpreter S1

## Objective

Build the first end-to-end `basic-software-interpreter` sandbox round: a
minimal LogicIR fixture calls one software provider function through a resolved
stack/profile contract and returns a deterministic output.

## Round Target

- Stack: `basic-software-interpreter`
- Round: `S1 pure invocation`
- End-to-end chain: `LogicIR fixture -> stack/profile resolver -> interpreter execution plan -> software engine -> output assertion`
- Required fixture: `src/fixture.ts`
- Required verification command: `yarn verify`
- Expected promotable output: minimal stack/profile shape, resolver shape,
  interpreter-plan projection shape, synchronous provider invocation engine
  shape, and a pure invocation fixture.

## Scope

In scope:

- Minimal S1 architecture data for `basic-software-interpreter`.
- Minimal profile resolver for one IR profile, one projection profile, and one
  execution profile.
- Minimal interpreter execution plan for one combinational external LUI.
- Minimal synchronous software engine that calls a provider from an explicit
  registry.
- Task-local TypeScript smoke verification.

Out of scope:

- Formal changes to `packages/`, `schema/`, `docs/`, `dev/`, `examples/`, or
  `fixtures/`.
- Type-system requiredness.
- retained-current state, completion/await, fulfillment/closure, lifecycle,
  scheduler, transport, generated JS, and HDL.
- Full validation or diagnostic model beyond fail-fast S1 errors.

- `design-notes.md`: design decisions, boundaries, alternatives, and risks.
- `package.json`: task-local verification scripts.
- `src/`: S1 architecture data, fixture, resolver, projector, engine, and
  smoke entry point.
- `dist/`: generated by `yarn build`; ignored by root `.gitignore`.
- `verification.md`: commands run, results, and known gaps.
- `promotion-checklist.md`: reviewed pieces that may later be moved to formal
