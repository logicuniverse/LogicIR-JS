# 开发流程

这一栏保存人与 AI 协作时的流程、边界和 review 记录方式。

## 内容

1. [process.md](process.md): 开发节奏、AI task 路由、promotion 和验证纪律。
2. [shared-rules.md](shared-rules.md): 跨会话共同规则。
3. [../changes/](../changes/): 粗粒度 change / review / decision 记录。

## 适用场景

- 准备新一轮 AI task。
- 准备人工 review。
- 判断某项内容该进 `ai/`、`dev/changes/` 还是正式目录。
- 判断一项修改是否该直接落地，还是先建立 change。
