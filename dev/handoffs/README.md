# Handoffs

这个目录保存交接记录。交接记录用于让后续的人或 AI 能从稳定状态继续，而不是依赖聊天上下文。

## 何时新增 handoff

- 一项工作跨越多个会话或需要暂停。
- 已经完成部分探索、计划或实现，但还有后续步骤。
- 发现重要风险、兼容问题或未决决策。
- 需要把验证结果和当前状态留给后续执行者。

## handoff 内容

每份 handoff 应尽量包含：

- 当前目标。
- 当前状态，明确哪些已经完成，哪些尚未完成。
- 已确认决策和关键假设。
- 相关文件或目录。
- 已运行的验证命令和结果。
- 风险、阻塞点和未决问题。
- 下一步建议，保持具体可执行。

## 命名建议

使用小写英文和日期前缀，例如：

```text
2026-05-11-schema-sync-handoff.md
2026-05-11-projector-review-handoff.md
```
