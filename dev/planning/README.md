# 当前规划

这一栏只放人类需要快速浏览的规划文档，并按“当前确定”与“中长期愿景”分开。

## 内容

1. [roadmap.md](roadmap.md): 当前确定要推进的工作。
2. [feature-catalog.md](feature-catalog.md): feature 状态和候选方向。
3. [long-term-vision.md](long-term-vision.md): 不确定的中长期 pressure tests。

## 边界

- `roadmap.md` 只跟踪当前确定路线。
- `feature-catalog.md` 只记录方向和状态，不制定 feature 数据结构。
- `long-term-vision.md` 保存远期愿景，不反向驱动当前实现。
